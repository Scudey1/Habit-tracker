Don-t-be-mean — это веб-приложение для формирования и отслеживания полезных привычек через механизмы геймификации.
Решаемая проблема: Пользователям сложно систематически выполнять рутинные или развивающие ежедневные задачи из-за отсутствия мотивации и визуализации прогресса.
Решение: Приложение предлагает:
    1. Ежедневный набор задач: Пользователь выбирает задачи из каталога на день.
    2. Мотивационную систему: За выполнение задач начисляется внутренняя валюта ("монеты").
    3. Визуализацию прогресса: Заработанные "монеты" можно потратить на виртуальную мебель в интерактивном магазине.
    4. Персонализированное пространство: Купленные предметы мебели украшают виртуальную "комнату" пользователя, которая служит наглядным отражением его достижений и прогресса.
Таким образом, фокус смещается с рутинного "выполнения задач" на увлекательный процесс "обустройства своего цифрового пространства".
